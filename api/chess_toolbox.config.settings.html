Mode d’affichage de la fenêtre Firefox pour l’automatisation Chessable.

HEADLESS = 'headless'

Navigateur sans rendu de fenêtre (--headless).

OFFSCREEN = 'offscreen'

Fenêtre réelle (pas de --headless) mais positionnée hors de tout écran physique après sa construction — invisible pour l’utilisateur sans les particularités de rendu/fingerprint du vrai mode headless.

VISIBLE = 'visible'

Fenêtre normale, visible à l’écran.
