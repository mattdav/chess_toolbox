chess_toolbox.bin.chessable_to_pgn.command_line module

Outils d’extraction des paramètres de ligne de commande.

Définit les modes de traitement de l’application et fournit les commandes du mode interactif.

Portage du projet chessable-to-pgn de John DeMastri (MIT), v0.3, chess@demastri.com.

chess_toolbox.bin.chessable_to_pgn.command_line.getNextItemToProcess()[source]

Boucle interactive : demande un cours ou une variation, puis les modes.

Return type:

tuple[bool, list[str] | None, list[str] | None]

Returns:

Tuple (quitter, cours saisis, variations saisies). quitter est True si l’utilisateur a demandé à sortir (‘q’).

chess_toolbox.bin.chessable_to_pgn.command_line.processCommandLineParams()[source]

Parse sys.argv et positionne les modes globaux WebFetch/Pgn.

Utilise argparse (parse_known_args) pour reproduire le comportement de l’ancien parsing manuel token par token : les flags à un seul tiret sont préservés à l’identique, et un argument inconnu affiche un avertissement au lieu de faire échouer le programme (pas de SystemExit).

Return type:

tuple[str | None, list[str] | None, list[str] | None]

Returns:

Tuple (mode de traitement, liste des cours, liste des variations). Retourne (None, None, None) si un argument est invalide.
