chess_toolbox.utils.get_package_dir(subpackage)[source]

Retourne le chemin absolu d’un sous-package.

Utilise importlib.resources.files (Python 3.11+) pour résoudre les chemins au sein du package installé, qu’il tourne depuis les sources ou depuis un wheel.

Parameters:

subpackage (str) – Nom du sous-package (ex. “config”, “data”, “log”).

Return type:

Path

Returns:

Chemin absolu vers le dossier du sous-package.

Raises:

ModuleNotFoundError – Si le sous-package n’existe pas.

Examples

>>> p = get_package_dir("config")
>>> p.name
'config'
